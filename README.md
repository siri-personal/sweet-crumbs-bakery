# Sweet Crumbs Bakery 🍰

A modern, responsive bakery website designed for Sweet Crumbs Bakery, a fictional bakery based in Indiranagar, Bengaluru.

## 🌸 Features

- Responsive desktop and mobile design
- Elegant bakery-themed UI
- Hero section with call-to-action buttons
- Bakery specialties section
- Image gallery
- About section
- Contact section
- WhatsApp ordering button
- Smooth navigation between sections

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Web Design
- Git & GitHub
